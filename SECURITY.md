# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public GitHub issues.

Citadel prefers GitHub's private vulnerability reporting flow. Once enabled by
the repository owner, use the **Report a vulnerability** button on the
[Security Advisories page](https://github.com/franadoriv/citadel/security/advisories).
That creates a private report visible only to the repository maintainers so a
fix and coordinated disclosure can be prepared safely.

Include a clear description, affected versions or commit, reproduction steps,
impact, and any suggested mitigation. Please allow maintainers reasonable time
to investigate and release a fix before public disclosure.

## Scope

Report vulnerabilities in Citadel's server, shipped client SDKs, release
artifacts, and official documentation/examples. Ordinary bugs, feature
requests, and support questions belong in GitHub Issues.

## Supported versions

Security fixes are prioritized for the latest released version and the current
`develop` branch.
