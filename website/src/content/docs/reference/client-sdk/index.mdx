Client SDK pages document the APIs a game client can call or bind to. Examples on
these pages should use synchronized engine tabs for every shipped client target:
Unreal C++, Unreal Blueprint, Unity C#, Godot GDScript, Rust
(`citadel-client`), and JavaScript/Web when the surface exists there.

:::note[Current shipped targets]
Citadel ships Unreal, Unity, Godot (native plus a Godot Web export), Rust, and a WebSocket JavaScript SDK today.
JavaScript examples appear for connection, authentication, generic RPC, and
notification streams; binary engine helpers remain engine-specific.
:::

## SDK bindings

From a repository checkout, use `make bin-client-<engine>` to stage the
copy-into-project package under `bin/clients/<engine>/`; see
[Make targets](/reference/operations/make-targets/#bin-client-engine-and-bin-clients).
JavaScript is currently staged from source rather than installed from npm.
For a visual browser-game integration, begin with the runnable
[`@citadel/client` + Three.js starter](/guides/web-client/); the SDK itself
remains renderer-neutral.
