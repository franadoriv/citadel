Server SDK pages document APIs that run inside or alongside the Citadel server:
runtime hooks, RPC handlers, authoritative simulation helpers, and server-side
message send/broadcast operations.

:::note[Current shipped runtimes]
Lua ships in the default embedded server runtime. Python ships as an embedded
CPython trusted-tier runtime with `--features runtime-python`. JavaScript ships
as capped embedded QuickJS with `--features runtime-js`.
:::
